# AI 隨身筆記

一個概念一頁、3 分鐘讀完的 AI 學習筆記網站。

- 純 HTML + CSS，不需要安裝任何東西
- 使用 GitHub Pages 部署
- 協作規則寫在 [`AGENTS.md`](AGENTS.md)，AI 讀完就能依照同一套格式繼續新增筆記

## 如何新增一篇筆記

對 AI 說：

> 請先閱讀 AGENTS.md，然後新增一篇關於「○○」的筆記。

AI 會依照 AGENTS.md 的流程建立新頁面，並自動更新首頁與前後頁連結。
