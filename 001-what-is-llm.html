NOTE 001

什麼是大型語言模型（LLM）

ChatGPT、Claude 背後的核心技術，其實是一個超強的「接龍機器」。

基礎LLM
一句話解釋

讀過海量文字、很會猜「下一個字」的程式。

核心概念

  • 大型語言模型（Large Language Model, LLM）是用大量文字資料訓練出來的程式，ChatGPT、Claude、Gemini 都屬於這一類。
  • 它的基本工作只有一件事：根據前面的文字，預測接下來最可能出現的字，一個字一個字往下寫。
  • 「大型」指的是模型裡可調整的參數非常多，加上訓練資料量很大，所以能學到文法、常識和各種寫作風格。
  • LLM 沒有在「查資料」，而是用學到的語言規律生成答案，所以它可能講得很順，但內容是錯的。

生活化例子

想像一個看完圖書館所有書的同學，你說「今天天氣真」，他馬上接「好」。你問他期末報告怎麼寫，他也能接出一整段像樣的內容。

但他是靠「讀過很多類似的句子」在接話，不是真的去翻書確認，所以偶爾會很有自信地講錯。

常見誤解

  • 很多人以為 LLM 像搜尋引擎一樣會上網找答案，其實基本的 LLM 只靠訓練時學到的內容回答，要另外接上搜尋功能才會查網路。
  • 很多人以為 AI 講得很有自信就代表是對的，其實它可能編出不存在的資料，這叫做幻覺（Hallucination）。
小練習：為什麼 LLM 有時會編造不存在的書名？

因為 LLM 是在預測「看起來合理的下一個字」，不是在資料庫裡查找。一個書名只要聽起來很合理，模型就可能生成出來，即使那本書根本不存在。所以重要資訊一定要自己再查證。
